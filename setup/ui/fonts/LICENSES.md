# The wizard's display face

The module titles, the cutscene title and ONLINE are set in League Gothic; everything else is the
system monospace. It is bundled so the page fetches nothing.

| File | Font | Source | Licence |
|---|---|---|---|
| `league-gothic.woff2` | League Gothic Regular, latin subset | The League of Moveable Type, as distributed by [Fontsource](https://fontsource.org/fonts/league-gothic) (`@fontsource/league-gothic` 5.3.0), unmodified | SIL Open Font License 1.1, in `OFL.md` |

League Gothic is a Reserved Font Name: a modified copy of this file may not be called League
Gothic. Add a new font file to `STATIC` in `scripts/setup_wizard.py`, or the wizard is refused it.
